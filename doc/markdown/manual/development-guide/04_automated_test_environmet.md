# Automated Test Environment

xxQS_NAMExx comes with a TCL/Expect based test environment that allows to automate the execution of tests. This
test framework can also be integrated in a CI/CD framework.

The tests of a release line can be registered as `ctest` tests and be run from an IDE, distributed over several
test clusters that share one code base. How to switch this on is described in *Register the Testsuite as CTest
Tests* in [Prepare the Build Configuration](#prepare-the-build-configuration); the tools to set up the test
clusters and to run the tests are documented in *`<testsuite>/tools/doc/`*.
